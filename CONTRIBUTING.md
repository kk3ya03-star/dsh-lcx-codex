# 参与贡献 / Contributing

**简体中文** · [English](#english)

感谢你愿意帮助改进 LCX Codex！

## 反馈问题和建议（推荐）

请通过 [Issues](https://github.com/kk3ya03-star/dsh-lcx-codex/issues/new/choose) 反馈：

- **Bug 反馈**：附上插件版本、DSH 版本（`dsh --version`）、Node.js 版本、使用的模型/网关类型和复现步骤。
- **功能建议**：说明使用场景和期望的效果。

**请不要上传 API Key、完整请求内容或未脱敏的会话日志。**

## 关于 Pull Request

本仓库是插件的**公开发布仓库**，日常开发、测试和发布审核在另一个仓库中进行，每个版本都会重新从那里导出。因此：

- 直接提交到本仓库的 PR **不会被合并**，否则会在下一次发布时被覆盖。
- 你仍然可以提交 PR 作为参考。我们会阅读，有价值的思路会在后续版本中重新实现，并在更新日志中致谢。
- 在动手写代码之前，建议先开一个 Issue 讨论，避免白费功夫。

## English

Thank you for helping improve LCX Codex!

### Reporting bugs and ideas (preferred)

Please use [Issues](https://github.com/kk3ya03-star/dsh-lcx-codex/issues/new/choose):

- **Bug reports**: include the plugin version, DSH version (`dsh --version`), Node.js version, model/gateway type, and reproduction steps.
- **Feature requests**: describe the use case and the expected behavior.

**Do not post API keys, full requests, or unredacted session logs.**

### About pull requests

This repository is the plugin's **public release repository**. Development, testing and release review happen elsewhere, and every release is re-exported from there. Therefore:

- Pull requests to this repository are **not merged directly**; they would be overwritten by the next release.
- You are still welcome to open a pull request as a reference. We read them, re-implement useful ideas in a later release, and credit you in the changelog.
- Please open an issue to discuss before writing code, so your effort is not wasted.
